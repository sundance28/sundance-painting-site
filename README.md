# Sundance Painting — Website

Quiet luxury one-pager for custom high-end residential painting (Northern California). Soft navy + cream + gold accents from the logo sun. Real facts only.

## Open locally

```bash
cd /workspace/sundance-painting-site
python3 -m http.server 8080
```

Then open `http://127.0.0.1:8080`.

## Files

- `index.html` — single page
- `styles.css` — styles (Cormorant Garamond + Source Sans 3 via Google Fonts)
- `main.js` — mobile nav + mailto form helper
- `assets/logo.jpg` — logo
- `assets/jobs/` — job and crew photos
- `assets/crew/` — crew portraits
